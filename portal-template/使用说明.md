# 通用蓝色三栏网站模板

本包提取自你上传的 sohoearning 网站模板。保留原配色、三栏版式、双层导航、样式中的视觉规则、导航背景和中性人物插画；站名、文章、公告、分类均已替换为通用示例。

## 打开和修改

1. 解压后直接双击 index.html，用 Chrome 或 Edge 打开。不需要终端、Node.js、ASP、数据库或联网。
2. 双击“配置工具.html”，填写站名、介绍、导航名称、栏目名称和文章。
3. 点击“导出配置文件”，将下载的 content.js 复制回模板文件夹，替换原文件。
4. 刷新首页。可在 assets 中放自己的图片，template.css 修改尺寸和颜色。

首页 index.html；栏目页 category.html；文章页 article.html；搜索页 search.html；内容配置 content.js；新增样式 template.css；抽取的原视觉样式 assets/original.css。

配置工具支持新增文章。分类/顶部导航工具保留当前行数，只改名称；如需增减分类，可直接编辑 content.js 中的 categories 数组。navigation 中的 href 用于调整站内导航链接。示例邮箱不是实际联系方式。

## 提取范围

没有打包原网站 ASP 程序、后台、备份、数据库、站点验证文件、站名标志、原文章、广告脚本、统计脚本和推广地址。original.css 仅保留视觉组件部分，不保留旧 IE expression 或后台系统样式。assets/SOURCE.md 记录素材出处。

这是前端展示模板：本地搜索读取自己的文章；配置工具导出文件，不自动保存到磁盘。没有服务端管理、登录、支付或原站业务接口。可部署到普通静态网站托管服务。
