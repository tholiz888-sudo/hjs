# 浪浪研究室后台界面复刻

基于提供的 8 张截图实现，无外部运行依赖。

## 运行

```sh
cd /workspace/hjs
npm run dev
```

默认端口 3000，可通过 PORT 覆盖。`npm run check` 检查脚本语法。

支持概览、交易记录、深度复盘、交易绩效、累计收益、止盈止损、盈亏比、直播回放；支持导航折叠、交易筛选/排序/分页/CSV 下载、指标切换、日期校验、交易选择、字幕/总结切换与深色模式。

前 10 条交易及绩效指标来自截图，其余交易、行情和分析曲线为演示数据。原始视频、账户登录、订阅支付和 AI 服务未接入。没有使用原站账号密码，也没有保存用户凭证。

## 独立登录与数据管理

使用 Node.js 24（内置 SQLite）。右上角“登录 / 注册”创建本站账户；密码至少 10 位。登录后点击“我的后台”，可添加和删除自己的交易。SQLite 数据位于忽略目录 `.local/`，重启服务器后保留。密码使用随机盐与 scrypt 哈希，会话使用 HttpOnly、SameSite Cookie。

所有新注册账户默认普通成员。注册后，服务器维护者可执行 `node scripts/make-admin.js 邮箱` 授予管理员权限。管理员可在“我的后台”查看用户列表，不可读取密码。没有内置管理员账号或默认密码。

这是可运行的基础版本。公开部署需要 HTTPS、持久化磁盘及数据库备份；HTTPS 部署时设置 `COOKIE_SECURE=1`。邮件验证、密码找回、支付及完整交易数据分析尚未实现。`.local/` 数据库不可放入公开下载包。

## 不懂代码时如何查看

`后台演示.html` 是独立界面演示文件，下载到电脑后双击，用 Chrome 或 Edge 打开即可查看和点击页面。此文件不包含服务器，不能实现账户登录和保存交易。

完整登录版本需在服务器运行本项目。本云环境未提供公网端口或部署工具，因此没有生成在线演示网址。要让普通浏览器通过网址访问，需要部署到用户提供的托管服务或服务器。

## Render 部署

`render.yaml` 提供免费预览配置。将代码推送到 GitHub 后，在 Render 选择 New → Blueprint，并连接对应仓库；或 New → Web Service，选择 Node，Build Command 填 `npm run check`，Start Command 填 `npm start`，环境变量设置 `NODE_VERSION=24.19.0`、`COOKIE_SECURE=1`。

免费服务的文件系统不持久化：重新部署、重建或重启后，本地 SQLite 账户及交易可能丢失。免费方案只适合试用界面和流程。正式保存数据需选支持磁盘的付费 Web Service，添加持久磁盘（例如挂载 `/var/data`），设置 `DATA_DIR=/var/data`。磁盘及服务费用以 Render 创建页面显示为准，此项目不会自动开通付费套餐。

部署完成后 Render 会提供 HTTPS 地址。打开地址，点击右上角“登录 / 注册”，注册自己的新账户；原网站账号不能登录本系统。
