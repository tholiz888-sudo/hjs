# 链上研习社
蓝色门户模板，首页和栏目页三栏，文章详情页只有正文和右栏。包含 23 篇基础教程（新手入门 11 篇）、搜索、手续费计算器、行情、金十快讯正文和 RSI/EMA/量比观察。

## Render 部署
新建 Web Service，连接 `tholiz888-sudo/hjs`，选择 **crypto-site** 分支（该分支网站文件位于根目录）。运行环境 Node，Build Command `npm run check && npm test`，Start Command `npm start`，免费实例即可。部署成功后打开 Render 生成的网址。免费实例休眠后首次访问可能较慢。

若选择 main 分支，Root Directory 填 `crypto-site`。已有交易复盘服务仍可保留；main 分支的旧服务也挂载 `/crypto/` 预览入口。

## 配置站名、返佣、社群
编辑 `site-config.json`：name 站名、tagline 标语、contact 联系方式；social 的 telegram/x/wechat 填 HTTPS 地址；exchanges 中 referralUrl 填你获得授权的邀请地址、code 填邀请码、discountPercent 填经过官方确认的减免比例。未确认时保留 null，链接为空时按钮只去官网。提交后 Render 重新部署。不要填交易所账号密码或 API 密钥。

## 本地启动
安装 Node.js 24，然后在本文件夹打开终端运行 `npm start`，浏览器打开 http://localhost:3000 。不需要安装第三方依赖。修改源码后重启服务。

## 数据说明
行情在服务端请求 CoinGecko 或 OKX，缓存三分钟；浏览器每分钟检查更新。量化榜使用 OKX 已收盘 1H 数据，计算 Wilder RSI14、EMA20 和量比，并非 AI 模型预测。快讯由服务端每分钟采集金十快讯列表中的文字正文，在本站直接展示，不提供站外跳转。数据源可能限流或因所在地区不可用，页面会显示错误；已有缓存过期后请求失败，会明确标注旧数据。没有伪造行情或信号。

本版不含后台编辑器、付费订阅或 AI 模型调用。内容在 data.js 编辑；真实 AI 服务需另行配置模型和预算。搜索和教程无需外部接口，计算器在浏览器本地运行。

## 验证
`npm run check && npm test`。健康检查 `/health`；SEO 页面由服务端渲染，提供 sitemap.xml、robots.txt、文章 JSON-LD。Render 自动提供域名时会用于 canonical；自定义域名可设置 SITE_URL=https://你的域名。

## 金十定时采集
运行时自动启动采集，无访客时也会执行，每分钟最多请求一次，并合并同一进程的并发请求。固定请求地址为 https://www.jin10.com/flash_newest.js ，不执行返回的 JavaScript，只解析 JSON 数据。金十时间按北京时间转换，快讯时间在页面统一按北京时间显示（采集状态时间仍按浏览器本地时区显示）。错误页、格式变化、无有效条目和超时均作为失败处理，不生成快讯。

快讯缓存默认保存在 storage/jin10-news.json；可设置 DATA_DIR 指定保存目录（挂载主应用时建议使用独立目录）。Render 免费服务的磁盘不持久，重新部署后缓存可能清空，服务恢复时会重新采集。若需要长期保存，给服务挂载持久磁盘并设置 DATA_DIR。免费服务休眠时定时器暂停，唤醒后重新采集；持续全天采集需要不休眠的实例。本版只轮询最新列表，不保证补齐停机期间的全部历史快讯。

当前开发环境对金十域名返回代理连接 403，因此真实响应尚未验证；解析、去重、定时、缓存恢复和失败降级使用构造样本测试通过。部署后需确认 /api/news 能返回真实快讯。如果金十更改公开接口或限制访问，需要根据其实际接口说明更新适配器，不应将页面错误或模拟数据作为实时新闻。

快讯采用左侧时分秒、右侧标题和正文的时间流排版，按北京时间分日；重要条目显示红色。原数据包含的段落与换行予以保留，不添加 VIP、PLUS 或付费标签。

快讯按正文语言过滤：采集、缓存恢复和页面展示均排除英文为主的消息，保留中文报道及其中的必要公司名或技术缩写；不会生成机器翻译。

币安专属注册教程位于 /articles/binance-registration，从交易所页面、左栏与右栏可进入。注册按钮复用 site-config.json 中币安的 referralUrl 和 code；未配置时只访问官网，不显示虚构的邀请码或折扣。

## 浪浪复盘栏目
顶部导航最右侧的“浪浪复盘”进入 /review，本地运行完整复盘程序，不使用远程网页内嵌。源码、样式、图表引擎与 4,806 笔交易数据均包含在 review/；账户、个人交易、导入导出及行情缓存通过 /review/api/ 处理。主应用挂载时相应地址为 /crypto/review 与 /crypto/review/api/。

已包含交易记录筛选分页、交易绩效、累计收益曲线、止盈止损、滚动盈亏比、K 线与指标、逐根回放、图表交互、账户注册登录和个人交易记录。原有未接入的 AI 与支付功能仍显示其真实状态；视频回放仍需提供可播放的视频源。没有因迁移而新增收费或生成虚构分析。

历史 K 线直接请求交易所接口，失败时可导入行情 CSV，不再通过旧 Render 服务转发。即使旧复盘站停服，本模块的程序和实盘数据仍可使用。交易所接口不可用时历史行情可能暂时无法获取，这与旧站是否在线无关。

### 账户数据与持久化
复盘数据库默认保存在 review/storage/dashboard.sqlite，使用独立 cookie 和账户接口。可用 REVIEW_DATA_DIR 指定持久目录。Render 免费实例的磁盘不持久，重新部署可能清空新增账户、个人记录与行情缓存；需要长期保存时将目录挂载到持久磁盘，并将 REVIEW_DATA_DIR 指向挂载目录。仓库里的 4,806 笔公开实盘数据不受此影响。

若通过 main 分支原服务的 /crypto/review 进入，默认复用原服务已有的交易数据库，账号与个人记录可以继续使用（显式设置 REVIEW_DATA_DIR 时改用该目录）。独立 crypto-site 服务无法读取另一项线上服务的磁盘；旧线上站点的私有账户与新增个人记录不在源码仓库内，不会随独立分支自动迁移。若需保留这些记录，应从旧服务取得一致的 SQLite 数据库备份，停止新复盘服务后放入 REVIEW_DATA_DIR/dashboard.sqlite，再启动服务。请先备份新数据库，避免覆盖已新增的数据。不要将数据库提交到 Git。

## 投研看剑栏目
顶部导航最右侧的“投研看剑”进入 /research。完整程序从同仓库 codex/jiange-deploy 分支 4c81ff4 迁入，保留 server/、数据快照、全部本地媒体、策略、智能选币、发现、数据聚合、个人中心、后台、会员与服务设置。它不是远程网页嵌套，不调用 hjs-2.onrender.com。主服务挂载路径为 /crypto/research。

该模块前端为本站提供的原生 ES 模块和 CSS，无需额外安装依赖或调用原网站构建。图片和文章数据已本地保存。实时行情仍直接请求交易所，外部邮件、推送和模型服务依原配置启用，不把历史快照或模拟结果冒充实时结果。首次访问本模块会初始化本地数据库和后台任务，之后自动任务随本站服务运行；Render 免费实例休眠期间暂停。

数据库用 RESEARCH_DB_PATH 指定，默认 research/storage/app.sqlite。格式与浪浪复盘数据库不同，应使用不同文件。旧线上服务的账号、会员、评论、收藏与后台设置不在源码仓库内，需要取得旧 SQLite 数据库备份后，在停止新模块服务时放入对应路径。不要覆盖已新增数据，也不要将数据库提交到 Git。长期保存仍需持久磁盘。

验证：门户集成测试覆盖子路径、静态资源、数据库、登录和收藏隔离；保留原程序 89 项单元/API测试，使用 npm run test:research 运行。浏览器检查覆盖门户入口、策略、历史指标、文章、数据、注册登录、图片和模块间导航，屏蔽旧域名后仍能使用。实际交易所连接应查看本模块的行情状态，不以离线测试作为连接成功的依据。
