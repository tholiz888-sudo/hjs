# 浪浪研究室复盘网站

根据用户提供的后台截图制作，现已接入用户上传的《实盘交易记录.xlsx》全部 4,806 笔、128 个交易对，时间范围 2022-05-24 至 2024-06-21。默认打开即可查看完整实盘数据，无需逐条手工导入。

## 运行与部署

使用 Node.js 24，内置 SQLite，不需要安装 npm 依赖。

```sh
npm run check
npm test
npm start
```

默认端口 3000，PORT 可覆盖。Render 的 `render.yaml` 已包含免费预览配置；推送更新后在 Render 执行 Manual Deploy → Deploy latest commit。HTTPS 部署设置 COOKIE_SECURE=1。

默认实盘数据文件随代码部署，不会因免费服务重启而丢失。独立用户账户和私人交易保存在 `.local/dashboard.sqlite`，或 DATA_DIR 指向的目录。Render 免费服务的文件系统不持久化，这部分数据可能在重部署后丢失。需长期保存账户时，使用支持持久磁盘的方案并将 DATA_DIR 指向挂载目录；费用以 Render 创建页面为准。

## 交易与报表

支持全量交易查询、按交易对筛选、列排序、分页和 CSV 导出；统计报告、累计收益、收益/收益率/持仓时间分布，以及滑动窗口盈亏比和胜率均从所选记录计算。可以切换完整实盘、10 笔样本和登录用户自己的交易；私人交易支持新增、编辑、删除和 CSV 批量导入（最多 1000 笔）。

原 Excel 的收益为手续费前收益；默认实盘净收益按原站口径使用收益＋负数手续费。保留原始收益率、原始收益、手续费、持仓价值、交易额与原始累计收益字段。统计复现：净收益 4,810,519.43 USDT，胜率 36.85%，盈亏比 3.44。原表累计收益列与独立按平仓时间累计的曲线不必逐行相同，原字段不被覆盖。

11 笔缺少平仓时间，保留缺失值。原站平均持仓时间按全部交易为分母计算为 101.87 分钟，有效平仓记录的均值为 102.10 分钟；界面注明两者口径。时间解释为 Asia/Shanghai（UTC+8）。私人记录的 profit 已是净收益，不重复扣费。

`data/trades.json` 是部署时的只读数据集，包含来源校验摘要。`scripts/convert-workbook.py` 可使用 openpyxl 将同列结构 Excel 转换为 JSON（运行网站不需要 Python 或 openpyxl）。原始 Excel 不放入公开源代码仓库。

## 行情、视频与 AI

深度复盘按所选交易的时间、交易对和周期，向固定 OKX 官方历史行情接口请求 OHLCV，显示蜡烛图、成交量、MACD 和逐根回放。接口不需要交易密钥，无法获取时显示错误，支持导入 `pair,time,open,high,low,close,volume` CSV。文件只含成交记录，不含历史行情；云环境实际访问 OKX 被网络限制，在线行情尚未确认成功。退市交易对也可能没有数据。最多请求 1800 根；覆盖不足时提示调整周期。

直播回放支持用户提供的 YouTube 视频链接或 HTTPS MP4 直链，是否可播放取决于源的权限和网络。原站视频、完整字幕、AI 服务及支付没有提供，尚未接入；不会伪造相应结果。持仓波动分析也需要行情覆盖整个持仓时间。

## 账户

右上角注册本站独立账户，密码至少 10 位。密码使用随机盐+scrypt，会话为 HttpOnly/SameSite Cookie。所有新用户为普通成员。服务器维护者在用户明确授权后，可执行 `node scripts/make-admin.js 邮箱` 赋予已注册账户管理员权限。没有默认账户、默认密码或原站凭证。

## 验证

`npm test` 检查账户/交易 CRUD、隔离和原子导入，Excel 数据完整性及截图统计对照，历史行情接口适配器的模拟响应与失败分支。浏览器检查全量加载、分页/筛选、统计值、累计收益日期筛选、分布/滑动窗口、交易选择及模拟行情绘图；这些不等于外部行情或 Render 线上访问已成功。

## 复盘页布局更新

复盘页使用固定顶栏＋铺满视口的四个图表区域＋160px 右侧纵向详情，去除原来的面包屑与大块导入卡片。首次打开完整实盘时默认选择对照截图中的第 141 笔 ETH 交易；也可在顶部输入序号、前后切换，或搜索序号/交易对。详情保留原始收益 228 USDT，并另外显示扣手续费后的净收益，避免混淆两种口径。

图表支持十字光标与时间/数值标签、鼠标滚轮缩放、拖动平移、双击/定位按钮复位、逐根回放、趋势线绘制和指标显隐。手机上图表全宽展示，详情位于顶栏“详情”按钮。导入行情和私人数据源位于齿轮设置中。底部时间范围按钮会更换周期并请求对应历史区间；受上游历史覆盖和 1800 根上限限制。

第四区域的“持仓山寨币种数量”由已知交易开平仓时间推算，排除 BTC，重复持仓按不同交易对计数，缺少平仓时间的记录不参与；这是交易记录推算值，不是交易所账户实时持仓。

这不是原站使用的 TradingView 完整终端：目前提供蜡烛图、成交量、MACD、持仓数量与上述交互，未实现其全部绘图类型、下单模拟系统或 AI 助手。浏览器布局验证使用明确标注的测试行情，不代表测试图中的价格是历史真实行情。

## 本地行情连接失败

网站能显示但历史行情连接失败时，代表行情请求不可达，而不是 Excel 数据丢失。本地通过 localhost/127.0.0.1 打开时，会同时请求 OKX 和固定在线站点 `https://hjs-fqyj.onrender.com/api/candles` 获取行情，使用最先成功的结果并取消较慢的通道。在线 Render 服务和带转发标记的请求不会再次转发，避免循环。只发送交易对、周期、时间范围；保留 TLS 校验。备用方式要求本机能访问在线站点，尚不能保证在用户网络可用。

成功获取的历史行情会保存至本地 SQLite 的 market_cache（最多 100 个区间），服务器重启后可继续读取，同区间已缓存时无需联网。首次未成功获取的区间不能离线生成 K 线，仍可导入行情 CSV。

Windows 解压新版到文件夹后，可双击 `启动网站.cmd`，保持窗口打开，在浏览器打开 http://localhost:3000。需先安装 Node.js 24。已有私人记录时保留旧文件夹的 `.local` 数据目录，更新代码不要删除它。

本地不再等待直连超时后才启用备用站点。重复的同区间请求在服务器合并，已缓存的请求优先读取本地 SQLite。首次未缓存的请求仍受本机网络与 Render 免费服务休眠启动时间影响，不能保证瞬间加载。

## 独立三栏门户页面

`retro-site/index.html` 是根据新截图制作的独立页面，不替换交易网站。可以直接双击打开，或在现有服务访问 `/retro-site/`。所有样式、插画与交互内嵌，无需联网或 Node；服务器仅用于在线展示。只提供了首页截图，因此内页使用明确标注的示例正文，广告使用占位，头像为独立插画。搜索、栏目和文章返回已验证。

## 提取的通用网站模板

用户上传原站源码后，已将真实视觉模板提取至 `portal-template/`，使用原导航装饰、原中性头像和原视觉规则，全部内容改成通用示例，不包含原 ASP 后台和业务数据。首页、栏目、文章、搜索页均可离线双击打开；`配置工具.html` 可编辑站名/栏目/文章并导出 content.js。Node 服务额外提供 `/portal-template/` 预览入口，不改变原交易首页或之前截图复刻页面。独立模板分支与压缩包只包含此目录内容。
