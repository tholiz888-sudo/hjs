# 原站策略导入

管理员登录后进入 **后台 → 策略采集**。点“立即采集”会按原站公开前端使用的只读接口读取配置及四个分类；勾选“启用定时采集”后，服务运行期间按设置间隔执行，最短30分钟。Render免费服务休眠时不执行定时任务。

所有导入记录均为草稿，在“手动策略”中检查后手动发布。来源、原站ID、原发布时间和导入时间随记录保存；重复来源ID不会覆盖草稿或已发布内容，也不会自动同步后续原站修改。系统不替原站生成缺失的入场、止损或目标价格。策略行情更新仍依赖本站行情采集器。

## 访问限制

本版本不保存原站账号密码，不使用原站管理员接口，也不绕过VIP、登录、验证码或防火墙。按原站普通用户规则过滤VIP遮罩及尚在12小时保护期的策略。401/403会记录失败并停止本轮；失败后至少冷却1小时。当前开发环境实际访问原站返回HTTP403，所以**已完成导入功能不等于原站已允许自动采集**。如果部署环境同样被拒绝，需要原站提供允许使用的数据出口才能接通。

后台同时提供JSON手动导入备用入口；只能导入有权使用的公开记录，仍执行同样的过滤。示例（选择“大饼以太”）：

```json
[{"id":1,"symbol":"BTC","side":"long","entry_price":"80000","stop_loss":"78000","target":"82000/84000/86000","created_at":"2026-01-01T00:00:00Z","remark":"待审核"}]
```

原站分类映射：tradfi→美股，main_future→大饼以太，futures→主流合约，futures_ambush→贵金属油。价格仅接受单个正数，目标必须是三个以斜杠分隔的正数。区间、星号、缺失字段和停用记录会跳过。

草稿、去重记录、采集设置及最近50次运行结果存储在同一SQLite数据库中。需要持久磁盘才能在Render重新部署后保留。

验证：`npm test`；`npm run build && node tests/strategy-import-browser.mjs`。浏览器用受控的403及JSON样本验证完整审核发布流程，不代表原站实时采集成功。
