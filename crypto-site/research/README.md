# 投研看剑 · 本站完整模块
从同仓库 codex/jiange-deploy 分支 4c81ff4 迁入。保留服务端、数据、全部静态媒体及前端功能，通过门户 /research 路径运行，不嵌套 hjs-2.onrender.com，不调用该旧服务。

本模块前端只使用本地 ES 模块和静态 CSS，迁入后直接由 Node 服务提供，不再要求 Vite 构建或安装前端依赖。Web 文件放在 web/，服务端在 server/，历史资料在 data/。原有测试和能力说明保留在 tests/ 和 docs/。

运行方式：在门户根目录 npm start，点击顶部最右侧“投研看剑”。MARKET_AUTO_SYNC=0 可关闭自动行情；RESEARCH_DB_PATH 可指定本模块 SQLite 文件，默认 storage/app.sqlite。与复盘数据库格式不同，不要填复盘数据库的地址。生产数据需要持久磁盘和备份。

此模块保留独立账号、收藏、积分、评论、策略管理、后台和服务设置。外部行情、邮件、推送及模型依照原有配置启用；没有凭证或授权时不声称相关服务已连接。旧线上站的私有账号、会员、评论和设置需取得数据库备份后迁入，不在源码快照里。
