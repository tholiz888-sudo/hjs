## 在自己的电脑运行

1. 安装Node.js 24或更高版本。
2. 解压本运行包，把采集工具的output/original文件夹复制到本项目的data目录，形成data/original/文件名，不要额外套一层original。
3. 双击RUN.cmd；或在本目录执行npm start。不需要安装第三方依赖。
4. 在自己电脑浏览器访问 http://localhost:3030 。点击页面后开始播放背景音乐，符合现代浏览器的用户手势要求。
5. npm run check核对导入数量；npm test执行文件、音频格式、链接和HTTP播放测试。

运行包只含代码和清单，不再重复附带约794MB素材。已安装旧基础包时可以覆盖代码，保留data/original。
