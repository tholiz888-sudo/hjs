# 仓位实验室 · Crypto Position Calculator

简体中文、浏览器本地运行的 USDT 本位线性永续合约规划工具。独立 Next.js 项目，与仓库原有网站互不影响。无需登录、数据库、交易所 API Key 或私钥，不提供下单功能。

## 启动

需要 Node.js 24+。

```bash
cd position-calculator
npm ci
npm run dev
```

默认端口 3000，若原站已占用，可执行 `npm run dev -- --port 3100`。生产环境：

```bash
npm run build
npm start -- --port 3100
```

## 主要用法：最多亏多少，该投多少保证金

默认使用「按亏损金额」：直接填写计划最多亏损（如 100 USDT）、杠杆倍数（如 100×）、入场价和止损价，最醒目显示建议投入保证金，同时给出保证金加开仓费合计。账户权益用于资金充足性校验；也可切回「按账户比例」模式，两种模式切换时保留等额风险预算。

不计费用时，100 倍杠杆、预算 100 USDT、入场 100000、止损 99000，计算出保证金 100 USDT；止损改为 99500 时为 200 USDT。手续费、滑点与资金费仍计入预算，开启成本后结果会相应减少。

新计划默认预算 100 USDT、杠杆 100×；其余默认 BTC 价格和费用保持不变，初始保证金为 143.15073 USDT，预估止损净亏损 99.9997854 USDT。50× 及以上会提示可能在计划止损前强平，不能将预算视为实际亏损保证封顶。旧版本的偏好和保存计划会迁移为等额亏损金额，保留原杠杆等参数。

## 功能

- BTC、ETH 和自定义标的，多空切换；即时风险仓位、名义价值、保证金及净止损亏损计算。
- 自定义账户权益、风险比例与上限、杠杆、开平仓手续费、往返滑点及持仓期资金费成本。
- 理论数量与按配置数量步长向下取整的数量分开显示；金额和模拟均使用取整数量。
- 两档 R 倍数 / 指定价格止盈、可编辑分批比例、全仓与分批收益、保证金净收益率、毛净盈亏比，以及 TP1 后剩余触发原止损的场景。
- 可交互净盈亏图，标出止损、入场、盈亏平衡与 TP；手机端补充价格图例。
- 复制动态交易计划；localStorage 保存/载入/删除最近 100 条计划与输入偏好；深浅主题，默认深色。
- 输入校验、保证金不足、最小数量、价格步长和分批数量不符合规则等提示。规则为手工配置示例，未伪装成交易所实时规则。

## 数学与假设

全部关键计算使用 Decimal.js（120 位精度）。输入值不自动纠正，不用浮点数计算关键金额。只有绘图坐标在归一化后转换为 JavaScript number。

- 风险预算 = 直接填写的亏损金额；比例模式下 = 权益 × 风险百分比 / 100。
- 单位止损总亏损 = 方向正确的止损价差 + 入场价 ×（开仓费率 + 往返滑点率 + 持仓期资金费成本率）+ 止损价 × 平仓费率。
- 理论数量 = 预算 / 单位总亏损；配置取整数量 = floor(预算 / (单位总亏损 × 数量步长)) × 数量步长。
- 名义仓位 = 取整数量 × 入场价；初始保证金 = 名义仓位 / 杠杆。
- 某退出价格的净利润 = 数量 ×（方向符号 × (退出价 − 入场价) − 入场价 × (开仓费率 + 滑点率 + 资金费率) − 退出价 × 平仓费率）。多头符号为 +1，空头为 −1。
- 盈亏平衡价 = 入场价 × (方向符号 + 开仓费率 + 滑点率 + 资金费率) / (方向符号 − 平仓费率)。
- 分批净利润 = 对应退出价格的全仓净利润 × 该档占比；总和与各批次完全一致，开仓及持仓成本按份额分摊，不重复计费。
- 1R 为入场和止损的价格距离；净 R 以取整后预估止损总亏损为分母。目标收益率为净利润 / 初始保证金，不是账户收益率。

页面输入费率单位都是百分比，例如 `0.04` 表示 `0.04%`。滑点按整个往返合计成本计一次，资金费按预计持仓期总成本计一次，均以入场名义价值为基数；只估算非负成本，不预测资金费返还。图为全仓于假设价格退出的净收益，不是分批止盈路径。所有目标成交属于假设，不承诺订单成交。

价格显示位数可设 0–12；显示四舍五入不会改写原始价格，数量保持完整。金额主卡片显示两位、成本明细四位，极小金额可能显示为零；核心计算和数量不因此截断。输入最多 80 字符，风险上限最高 100%，杠杆范围 1–200，成本项范围 0–10%。这些是工具的输入范围，并非推荐交易参数。

比例模式回归示例：权益 5000、风险 0.5%、入场 100200、止损 99600、5×，开/平费各 0.04%、滑点 0.02%、资金费 0%。预算 25 USDT，数量步长 0.000001，取整数量 0.035716 BTC，名义仓位 3578.7432 USDT，初始保证金 715.74864 USDT，预估止损净亏损 24.99977136 USDT。默认目标 101100 / 102000，各平 50%。

## 部署到 Vercel

1. 将代码推送到自己的 GitHub 仓库，在 Vercel 导入该仓库。
2. 将 **Root Directory** 设置为 `position-calculator`；框架选 **Next.js**，Node.js 选择 **24.x**。
3. 安装命令 `npm ci`，构建命令 `npm run build`，输出目录使用 Next.js 默认设置。
4. 不需要任何环境变量或数据库，点击 Deploy。HTTPS 可支持剪贴板 API。
5. 在部署域名验证计算、复制、刷新恢复及移动布局。localStorage 按域名隔离，不会自动同步到其他设备或预览域名。此项目未自动推送或部署。

## 风险与隐私

保证金不是最大亏损；真实亏损可能因滑点、跳空、资金费变化等超出预算。止损不保证按计划价格成交。没有实时维持保证金、仓位档位和账户参数，不能准确推算强平价，本工具不显示伪精确强平价。清除浏览器数据会删除计划；本地保存不等同云端备份。结果仅用于规划，不构成投资建议或盈利保证。

## 部署到 Render（免费 Web Service）

该目录内的 `render.yaml` 仅定义本计算器，仓库根目录的原站配置保持不变。使用 Node.js 24.22.1，无需数据库、磁盘或交易所密钥。

在 Render 创建 **Web Service**，连接 `tholiz888-sudo/hjs` 仓库后设置：

| 设置 | 值 |
| --- | --- |
| Name | `crypto-position-calculator`（名称被占用时可更改） |
| Branch | `codex/position-calculator-render` |
| Root Directory | `position-calculator` |
| Runtime | Node |
| Build Command | `npm ci --include=dev && npm run build` |
| Start Command | `npm start` |
| Instance Type | Free |
| Health Check Path | `/` |
| Environment | `NODE_VERSION=24.22.1`、`NEXT_TELEMETRY_DISABLED=1` |

不需要设置 `PORT`，Next.js 会读取 Render 自动提供的 `PORT` 并监听 `0.0.0.0`。构建时显式安装开发依赖，以便 TypeScript、Tailwind 和 Next.js 正常构建。若使用 Blueprint，自定义 Blueprint 文件路径选择 `position-calculator/render.yaml`，并选择上述分支；不要使用仓库根目录的原站 Blueprint。

部署成功后，在 Render 分配的 HTTPS 域名检查首页、仓位实时更新、计划保存与复制。Free 服务空闲时可能休眠，首次请求可能较慢。偏好和计划仍只在访问者浏览器保存，不会随 Render 服务重启丢失；不同域名的本地数据相互隔离。


## 按保证金反算止损价

输入区顶部可选择「按止损算保证金」或「按保证金算止损价」。前者需要开仓价和止损价，结果同时显示保证金与止损价格；后者输入投入保证金、杠杆、开仓价和亏损预算，以止损价格为主结果。仅有开仓价与亏损金额不足以确定唯一止损价，必须知道仓位大小，因此反算模式需要保证金。

反算先用 `投入保证金 × 杠杆 ÷ 入场价` 得到理论数量并按数量步长向下取整。固定这个数量后，令 `s` 为多单 +1、空单 -1，`a` 为开仓费率 + 往返滑点率 + 资金费成本率，`c` 为平仓费率，则：

`止损价 = (入场价 × (s + a) − 预算 / 数量) / (s − c)`。

按价格步长取整时，多单向上取整、空单向下取整，使止损靠近入场，含估算成本的亏损不超过预算，因此可能略低于输入的亏损金额。价格精度不足、预算不足以覆盖成本或取整后无有效止损空间时会显示错误。固定保证金模式中，改变杠杆会改变仓位和止损价；固定止损模式中，改变杠杆只改变保证金。

例：不计费用，100 倍、入场 100000、保证金 100 USDT、亏损预算 100 USDT，做多止损 99000，做空止损 101000。保证金 200 USDT 时分别为 99500 / 100500。止盈、图表、复制和保存均使用实际算出的止损价。反算价格不是强平价；高杠杆可能在到达该价格前强平。


## 简易版与专业版

页面顶部可随时切换，默认简易版；浏览器记住上次选择。

- 简易版只显示方向、标的、开仓价、杠杆、投入保证金和最多亏损金额，大字显示计划止损价。费用及账户权益收在可选设置里，计算仍包含设定成本；没有止盈表、图表和成本明细。
- 专业版保留两种计算方向、风险比例、止盈分批、图表、成本构成及完整规则设置。
- 输入数据共享。由专业版转到简易版时，将有效的预算和保证金带过去；止盈参数保留，但不会阻止简易计算。返回专业版后仍可继续编辑，未完成的止盈会在专业版显示校验错误。
- 简易计划可复制、保存、载入和删除；载入时恢复对应的简易或专业界面。旧计划仍兼容，不会删除。
- 金额和止损核心计算共用 Decimal 模块；简易版只跳过止盈相关计算和校验，不忽略仓位、费用、止损、资金和数量规则。

`components/simple/simple-calculator.tsx` 为简易界面，`lib/simple.ts` 管理简易输入映射和复制文本。浏览器测试同时覆盖两个版本、输入共享、版本偏好持久化、隐藏止盈隔离及桌面/手机布局。
